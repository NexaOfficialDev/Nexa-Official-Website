PUBLISH NEXA 1.0.0 WEBSITE

1. Extract this ZIP.
2. Open the Nexa-1.0.0-Complete folder.
3. Upload the CONTENTS of this folder to the root of:
   NexaOfficialDev/Nexa-Official-Website
   Make sure index.html, styles.css, script.js, assets, downloads, and snapshots are at the repository root.
4. On GitHub open Settings > Pages.
5. Choose Deploy from a branch, select main, choose /(root), then Save.
6. Wait for Pages to finish deploying.

The source ZIP, Nexa-1.0.0-x86-Setup.exe, and Nexa-1.0.0-MSI.zip downloads are active. The MSI ZIP includes both the MSI and required cab1.cab. Only snapshot downloads remain Coming Soon. Upload/commit the updated root index.html, downloads/index.html, README files, and downloads folder, wait for GitHub Pages to deploy, then hard-refresh with Ctrl+F5.
